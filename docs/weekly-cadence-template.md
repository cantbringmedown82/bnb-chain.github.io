# Weekly Cadence Template

This document outlines the weekly cadence for the BNB Chain project team.

## Weekly Schedule

### Monday
- **9:00 AM** - Week kickoff meeting
- **10:00 AM** - Sprint planning (if starting new sprint)
- Review previous week's meeting log
- Set priorities for the week

### Tuesday
- **2:00 PM** - Technical review session
- Code review and merge decisions
- Architecture discussions

### Wednesday
- **10:00 AM** - Mid-week sync
- Progress check-in
- Blocker resolution

### Thursday
- **3:00 PM** - Documentation review
- Update user guides
- Review meeting logs

### Friday
- **2:00 PM** - Weekly retrospective
- Create weekly meeting log
- Celebrate wins
- Identify improvements

## Meeting Expectations

### Preparation
- Review agenda before meeting
- Prepare updates and questions
- Review previous action items

### During Meeting
- Stay on topic
- Take notes
- Identify action items
- Assign owners

### After Meeting
- Create/update meeting log using [Meeting Log Template](meeting-log-template.md)
- Share meeting notes with team
- Update documentation as needed

## Communication Channels

- **Urgent Issues**: Direct message
- **General Updates**: Team channel
- **Documentation**: Pull requests
- **Governance**: Meeting logs and GOVERNANCE.md

## Action Item Tracking

All action items should be:
- Clearly defined
- Assigned to specific owner
- Have a due date
- Tracked in meeting logs

## Escalation Path

1. Team lead
2. Project manager
3. Steering committee
