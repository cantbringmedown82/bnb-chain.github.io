# Weekly Cadence Template

This template provides a structured approach to organizing weekly governance meetings and ensuring consistent communication.

## Weekly Schedule

### Monday
- **Team Sync** (Optional)
  - Quick alignment on week's priorities
  - Blocking issues escalation

### Wednesday
- **Mid-week Check-in** (Optional)
  - Progress updates on action items
  - Course corrections if needed

### Friday
- **Weekly Governance Meeting** (Required)
  - Time: 14:00 UTC
  - Duration: 60 minutes
  - Use the [Meeting Log Template](meeting-log-template.md)

## Meeting Preparation

### Before the Meeting (24 hours prior)
- [ ] Review previous meeting's action items
- [ ] Gather status updates from team members
- [ ] Prepare agenda with specific topics
- [ ] Share preliminary agenda with attendees
- [ ] Collect questions or concerns from community

### During the Meeting
- [ ] Start on time
- [ ] Follow the agenda
- [ ] Document decisions and action items in real-time
- [ ] Allow time for open discussion
- [ ] Confirm next steps and assignees

### After the Meeting (within 24 hours)
- [ ] Finalize meeting log using template
- [ ] Commit meeting log to `docs/meeting-logs/`
- [ ] Share summary with stakeholders
- [ ] Update project boards with new action items
- [ ] Set reminders for follow-up tasks

## Monthly Activities

### First Week
- Review previous month's achievements
- Set goals for current month
- Community feedback compilation

### Mid-Month
- Progress check on monthly goals
- Mid-month community update

### Last Week
- Month-end review
- Plan next month's priorities
- Prepare monthly governance report

## Quarterly Reviews

- Comprehensive governance metrics review
- Community survey and feedback analysis
- Strategic planning session
- Public quarterly report publication

## Communication Channels

- **Meeting Logs**: All logs stored in `docs/meeting-logs/`
- **Community Updates**: Published via official channels
- **Urgent Matters**: Use designated communication channels
- **Governance Badge**: Automatically updated via GitHub Actions

## Tips for Effective Meetings

1. **Be Prepared**: Review materials before the meeting
2. **Stay Focused**: Stick to the agenda and time limits
3. **Document Everything**: Decisions and action items must be recorded
4. **Follow Through**: Track and complete action items
5. **Be Inclusive**: Ensure all voices are heard
6. **Stay Transparent**: Share information openly with community

## Metrics to Track

- Meeting attendance
- Action item completion rate
- Time from decision to implementation
- Community engagement levels
- Governance participation metrics

## Continuous Improvement

- Regularly review and update this template
- Incorporate feedback from team and community
- Adapt cadence as project needs evolve
