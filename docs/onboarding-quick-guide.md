# Onboarding Quick Guide

Welcome to the BNB Chain governance and contribution ecosystem! This guide will help you get started quickly.

## Getting Started

### 1. Understand the Project
- Read the [README](../README.md) for project overview
- Review [GOVERNANCE.md](../GOVERNANCE.md) for governance structure
- Check out the [BNB Chain Documentation](https://docs.bnbchain.org)

### 2. Join the Community
- Follow official BNB Chain channels
- Join community discussions
- Introduce yourself and your interests

### 3. Set Up Your Development Environment
- Fork the repository
- Clone your fork locally
- Install required dependencies (see README)
- Run the documentation site locally: `mkdocs serve`

## Making Your First Contribution

### Step 1: Find an Issue
- Browse open issues
- Look for "good first issue" or "help wanted" labels
- Ask questions if anything is unclear

### Step 2: Prepare Your Contribution
- Read [CONTRIBUTING.md](../CONTRIBUTING.md)
- Follow the [Style Guide](style-guide.md)
- Make small, focused changes

### Step 3: Submit Your Work
- Create a feature branch
- Make your changes
- Write clear commit messages
- Submit a pull request
- Respond to review feedback

## Documentation Guidelines

### When to Update Documentation
- Adding new features
- Changing existing functionality
- Fixing bugs that affect documented behavior
- Improving clarity or accuracy

### Where to Find Templates
- [Meeting Log Template](meeting-log-template.md) - For governance meetings
- [Weekly Cadence Template](weekly-cadence-template.md) - For planning
- [Style Guide](style-guide.md) - For writing standards

## Governance Participation

### Attend Meetings
- Weekly governance meetings on Fridays at 14:00 UTC
- All meetings are open to community members
- Meeting logs published in `docs/meeting-logs/`

### Stay Informed
- Check the governance badge status: ![Governance Ledger Status](https://img.shields.io/badge/Governance%20Ledger-Up%20to%20Date-brightgreen)
- Review meeting logs regularly
- Follow action items and decisions

### Provide Feedback
- Share your ideas and concerns
- Participate in community discussions
- Help improve governance processes

## Common Tasks

### Building the Documentation
```bash
# Install dependencies
pip install mkdocs-material mkdocs-video mkdocs-redirects

# Serve locally
mkdocs serve

# Build for production
mkdocs build
```

### Updating Meeting Logs
1. Copy the [meeting log template](meeting-log-template.md)
2. Create new file: `docs/meeting-logs/YYYY-MM-DD-weekly-log.md`
3. Fill in meeting details
4. Submit via pull request
5. Governance badge updates automatically

### Proposing Changes
1. Open an issue describing your proposal
2. Discuss with community and maintainers
3. If approved, implement changes
4. Submit pull request with references to issue
5. Address review feedback

## Getting Help

### Questions?
- Check existing documentation first
- Search closed issues for similar questions
- Ask in community channels
- Open a new issue with detailed information

### Need Support?
- Technical issues: Open GitHub issue
- Security concerns: See [SECURITY.md](../SECURITY.md)
- General questions: Community channels
- Governance matters: Attend weekly meetings
