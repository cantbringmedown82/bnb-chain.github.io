## Guidelines for Using This Template

### Creating a New Meeting Log
1. Copy this template
2. Save as `docs/meeting-logs/YYYY-MM-DD-weekly-log.md`
3. Fill in all sections during or immediately after the meeting
4. Commit and push to trigger governance badge update

### Best Practices
- Be concise but complete
- Use clear, actionable language for action items
- Include links to relevant resources
- Tag team members when appropriate
- Update action items from previous meetings

### Action Item Format
Each action item should include:
- Clear description of what needs to be done
- Owner/assignee
- Due date
- Context if needed

### Review Process
1. Draft meeting log during meeting
2. Review and edit for clarity
3. Share with attendees for feedback
4. Finalize and commit within 24 hours of meeting
